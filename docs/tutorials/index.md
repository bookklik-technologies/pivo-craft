# Beginner tutorials

Learn PiVo Craft by building one small project from scratch. Work through these three lessons in order, or open a supplied checkpoint to start a later lesson.

Each lesson takes roughly 5–10 minutes and includes four screenshots from the actual app. Screenshots use the dark theme at 1440×900; click an image to open it at full size. Your window may differ, but the control labels are the same.

| Lesson | You will learn | Finished project |

| [1. Draw your first pixel face](/tutorials/first-sprite) | A yellow face with dark eyes and a smile, on a transparent 16×16 canvas. | <a href="./pixel-face.pvc" download>Download checkpoint</a> |
| [2. Make the face blink](/tutorials/blink) | Two independent frames with an 800 ms open-eye pose and a 200 ms closed-eye pose. | <a href="./blinking-face.pvc" download>Download checkpoint</a> |

## Before you start

Follow [Installation & running](/getting-started), open the app, and use a desktop mouse and keyboard. The tutorials describe visible menus and controls; Ctrl/Cmd means Control on Windows/Linux or Command on macOS. Save existing work before beginning a new project.

The checkpoint files are editable native projects. Download them, then use the app's Open command to choose the local file. Browser downloads may use the document's default name; rename them locally if you want the lesson's checkpoint names.

For a feature overview, see the [User guide](/guide). For import/export details, see [File formats](/formats).
